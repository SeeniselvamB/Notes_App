# Interactive Notes App

Professional Note Management Application

A modern and intuitive note-taking application built with React Native and Expo. The app helps users create, organize, edit, search, and manage notes efficiently through a clean and professional mobile interface.

---

## Features

### Create Notes
- Quickly create new notes
- Save important information instantly

### Edit Notes
- Update existing notes anytime
- Simple and user-friendly editing experience

### Organize Notes
- Manage notes efficiently
- Structured note storage

### Search Functionality
- Find notes instantly using keywords
- Fast and responsive search experience

### Local Storage
- Notes are stored locally on the device
- Persistent data using AsyncStorage

### Responsive User Interface
- Clean and modern design
- Optimized for Android devices

## Installation

### Clone the Repository

```bash
git clone https://github.com/SeeniselvamB/Notes_App
```

### Navigate to the Project Folder

```bash
cd notes-app
```

### Install Dependencies

```bash
npm install
```

### Start the Project

```bash
npx expo start
```

---

## 📦 Build APK

```bash
eas build -p android --profile preview
```
